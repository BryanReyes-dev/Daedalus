# Contributing to Daedalus

Thank you for considering a contribution to the Daedalus Rust runtime.

## Scope

This repository contains the public Rust runtime foundation and is licensed under the Apache License, Version 2.0. Contributions accepted into this repository are made available under Apache-2.0.

The proprietary Desktop application and Marketplace service are maintained separately. Do not submit code copied from those repositories or other proprietary sources.

## Developer Certificate of Origin

Contributors must certify that they have the right to submit their contributions under the project's license by adding a DCO sign-off to each commit:

```bash
git commit -s -m "your commit message"
```

The sign-off records the contributor's certification under the Developer Certificate of Origin 1.1. It does not transfer copyright ownership to the project maintainer and does not grant exclusive rights to relicense the contribution under a different license.

If a proposed contribution requires different licensing or a separate commercial/relicensing arrangement, do not submit it under the ordinary contribution flow. Contact the maintainer and obtain a separate written agreement before the contribution is accepted.

## Contribution expectations

- Read `agents-files/AGENTS.md` and `agents-files/ARCHITECTURE.md` before changing architecture or security boundaries.
- Keep changes scoped, tested, and documented.
- Do not claim support, security certification, or compliance that has not been independently verified.
- Include tests for behavioral changes and update the README or focused documentation when public behavior changes.
- Preserve existing license, copyright, attribution, and third-party notices.
- Identify any new third-party dependency and review its license before adding it.

## Third-party material

Only submit code, documentation, media, model weights, or other assets that you created or are authorized to contribute. Identify third-party material and its license. Do not assume this repository's Apache-2.0 license changes the terms of third-party components.
